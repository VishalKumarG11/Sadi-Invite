# Sadi Invite

A digital wedding invitation website for a marriage ceremony, designed with a modern and elegant landing-page style. The project presents the couple's wedding details, event schedule, venue information, family wishes, and a music-driven invitation experience.

## Overview

This repository contains a static HTML/CSS/JavaScript wedding invitation page that can be opened directly in a browser or deployed as a simple front-end site. It includes:

- Welcome hero section with couple names
- Wedding introduction and family details
- Event timeline for rituals and functions
- Countdown section for the wedding date
- Location map embed
- Audio integration for background music
- Responsive design for mobile and desktop screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 4
- Font Awesome
- Animate.css
- jQuery

## Local Usage

1. Clone the repository:

```bash
git clone https://github.com/VishalKumarG11/Sadi-Invite.git
```

2. Open the project folder:

```bash
cd Sadi-Invite
```

3. Open `index.html` in a browser.

You can also host it on GitHub Pages, Netlify, or any static web hosting service.

## Deployment

For GitHub Pages, simply push the repository and enable Pages from the repository settings.
